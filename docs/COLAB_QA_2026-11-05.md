## Diagnóstico

1. El notebook usó `npm ci` pero el repositorio no contiene lockfile. El flujo CI oficial emplea `npm install --no-audit --no-fund`. El fallo es del notebook.
2. La compilación completa CUDA con `cmake --build ... -j 2` seguía progresando cuando alcanzó el timeout. El log no demuestra error de incompatibilidad de la GPU; `nvcc: Terminated` aparece después de la detención por límite.
3. Para fines de validación en Colab, compilar desde cero no aporta suficiente valor frente a utilizar un binario oficial publicado y verificable.
